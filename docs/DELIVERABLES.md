# Deliverable mapping: final objectives

The ten objectives are the ones listed on the Review 3 "Final objectives" slide. For each one,
this table names the implementing files and the tests whose names cover it. Test names were taken
from `tests/`; this document does not record a test run. Run `pytest -q` to confirm the current
state. Evaluation figures are not quoted here (see `evaluation/RESULTS.md` once it is final).
